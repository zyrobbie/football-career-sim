# 绿茵生涯

一个以合同选择、职业生涯规划、技术特点和人际关系为核心的中国球员文字生涯模拟器。

在线试玩：[https://zyrobbie.github.io/football-career-sim/](https://zyrobbie.github.io/football-career-sim/)

当前阶段：可玩的青训两年、首份职业合同、第一个职业半年与首个国内转会窗口闭环已完成，覆盖：

> 建档 → 生成球员 → 三份青训邀请 → 入队事件 → 四个青训半年 → 一线队关注与晋升评估 → 首份职业合同与一次反报价 → 签约 → 职业半年策略 → 青年队或一线队比赛 → 工资与合同承诺结算 → 留队或比较三份国内报价 → 单次反报价 → 转会签约 → 新俱乐部融入事件 → 自动存档 → 读档恢复

建档完成后，所有选择都在常驻生涯主页中进行。主页持续显示球员总览、
能力与状态、关系、现金、青年队累计数据和逐窗口生涯履历。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

质量检查：

```bash
npm run typecheck
npm run test:run
npm run build
```

Demo 到15岁完成首个国内转会窗口为止。第二年可以进入观察名单、成为跟训候选、获得跟训机会或正式晋升；合同会根据实际晋升结果承诺青年队或一线队角色。签约后按实际球队层级模拟训练与比赛，并结算工资可支配收入、合同期限和角色承诺。首个转会窗口遵守未满16岁只允许国内流动的边界，报价与谈判结果会写入存档，刷新不会重抽。

## 开发原则

- 规则引擎、静态数据、界面和存档彼此分离。
- 页面不直接修改游戏数值，只提交玩家选择。
- 使用固定种子和模块化随机流，刷新或读档不能改变已生成结果。
- 存档只保存基础状态和历史摘要，不保存可重新计算的派生数据。
- Demo 使用完整版公式，不另写以后需要推翻的临时逻辑。
- 如果不能可靠验证，就不把脆弱原型标记为完成。
