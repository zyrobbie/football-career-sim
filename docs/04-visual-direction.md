# 绿茵生涯：视觉设计说明

状态：视觉概念已确认，可作为实现基准。

## 1. 核心方向

视觉关键词：

- 职业档案；
- 比赛日秩序感；
- 体育编辑设计；
- 清晰的数据层级；
- 克制而有质感；
- 移动端优先。

不采用通用SaaS后台或大面积卡片网格。游戏以文字和选择为核心，视觉身份主要来自排版、线条、留白和足球场几何，而不是照片、队徽或大量插画。

## 3. 设计系统

基础色值：

| Token | 色值 | 用途 |
|---|---|---|
| `shell` | `#082c23` | 应用外壳、侧栏、深色按钮 |
| `shellDeep` | `#05221b` | 深色层次 |
| `paper` | `#f3f0e8` | 主内容 |
| `paperMuted` | `#e9e4d9` | 表头、次级选中背景 |
| `ink` | `#12382d` | 标题、关键数字 |
| `text` | `#20231f` | 正文 |
| `muted` | `#6f716a` | 次要文字 |
| `gold` | `#bd9d56` | 强调、选中、边框 |
| `line` | `#c9c0ad` | 分隔线 |
| `positive` | `#1f6b43` | 正向变化 |
| `danger` | `#93483f` | 风险和负向变化 |

背景为浅纸张色，不是纯白。深色区域不使用蓝紫渐变或玻璃效果。

字体：

- 大标题和数字：`"Songti SC", "STSong", "Noto Serif SC", serif`；
- 正文与控件：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`；
- 拉丁数字启用`font-variant-numeric: tabular-nums`。

字号基线：

| 类型 | 桌面 | 手机 |
|---|---:|---:|
| 页面主标题 | 52至60px | 38至44px |
| 区域标题 | 26至32px | 24至28px |
| 正文 | 16至18px | 16px |
| 控件 | 16至18px | 16px |
| 辅助文字 | 13至14px | 13px |
| 关键综合能力 | 72至88px | 60至72px |

间距使用4、8、12、16、24、32、48、64的基础序列。

圆角以2、4、8px为主。选择卡和主按钮不使用大于10px的圆角。

图标：

- 20至24px线性图标；
- 1.5至2px描边；
- 使用`currentColor`；
- 不使用Emoji；
- 品牌只使用“绿茵生涯”文字标，不制作俱乐部式徽章；
- 虚构俱乐部使用单字方框标识，例如“沪、汉、桂”。

## 4. 组件与容器

- 外层：深墨绿；
- 主内容：纸张色或浅石色；
- 强调：低饱和金色；
- 正文：深炭灰；
- 辅助：灰绿；
- 风险：克制的砖红；
- 成功：与主绿色区分的明亮草绿。

容器：

- 使用开放区域、分隔线、轨道、清单和单一重点面板；
- 小圆角；
- 轻微阴影或无阴影；
- 避免层层嵌套卡片；
- 避免装饰性标签、胶囊和假指标。

桌面外壳：

- 最大宽度1536px；
- 左侧栏约220至250px；
- 内容区使用两列或主区加窄侧区；
- 主要内容离外壳边缘至少32px；
- 表格采用共享行基线，不把每一行做成卡片。

主要组件：

- `AppShell`
- `SidebarNav`
- `ProgressRail`
- `ChoiceList`
- `PlayerDossier`
- `AttributeTable`
- `StateChangeList`
- `OfferComparison`
- `ReportSummary`
- `PrimaryButton`
- `AutosaveStatus`

## 5. 主界面信息结构

桌面：

- 安静的顶部栏：游戏名、当前窗口、自动保存状态；
- 窄左侧生涯导航；
- 中央主要选择区；
- 右侧球员档案、状态、关系和现金；
- 主要按钮只出现一个；
- 选择项以整行或开放列表呈现。

手机：

- 顶部保留游戏名和当前窗口；
- 球员核心信息压缩为两行；
- 当前事件和选择优先；
- 状态与关系放入可展开区域；
- 主按钮保持在自然阅读流中，不使用遮挡内容的固定悬浮按钮。

## 6. 允许的视觉动效

- 窗口推进时的短暂时间轴移动；
- 选项确认后的细线或色块状态变化；
- 半年报告数字逐项显现；
- 能力变化的短距离过渡；
- 所有动效支持减少动态效果设置。

不使用：

- 夸张粒子；
- 霓虹发光；
- 大面积视差；
- 模拟比赛动画；
- 长时间等待动画。

## 8. 建档后的常驻生涯主页

建档完成后不再使用“独立决策页 + 侧边球员摘要”的结构。青训邀请、
入队事件、半年训练、半年报告和阶段完成都嵌入同一生涯操作台。

固定信息顺序：

1. 球员总览：综合能力、姓名、年龄、号码、位置、俱乐部、地位和现金；
2. 青年队累计：出场、进球、助攻与四项核心属性；
3. 六项状态：竞技、身体、心理、教练关系、队内关系和球迷关系；
4. 生涯履历：按半年保存俱乐部、地位、能力和比赛数据；
5. 当前事件：本窗口唯一需要玩家处理的选择或报告。

桌面端履历与当前事件并列，报告和青训邀请使用全宽内容区。手机端按以上
顺序单列排列，履历表在430像素宽度内显示，不产生页面级横向滚动；四项
导航固定在底部。
