# 绿茵生涯：产品与规则规格

版本：0.1  
状态：已确认规则基线  
游戏类型：中国球员文字职业生涯模拟器

## 1. 产品边界

玩家扮演一名被中国职业俱乐部青训营发掘的13岁中国球员，从青年队开始成长，最晚在40岁退役，也可以提前退役。

游戏的核心不是逐场操作，而是每半年作出一次职业选择，再由系统汇总模拟这半年发生的比赛、成长、关系和职业后果。

核心体验：

- 合同与转会选择；
- 职业生涯规划；
- 四项长期能力形成的技术特点；
- 教练、队友、经纪人、球迷和媒体关系；
- 选择带来的长期后果；
- 退役时由荣誉、表现数据和评价性标签共同总结生涯。

不包含：

- 门将位置；
- 难度等级；
- 真实球员、教练、球衣、队徽和赞助商；
- 完整俱乐部阵容；
- 逐场比赛操作；
- 买房、买车、投资和家庭生活模拟；
- 多个可见存档槽。

## 2. 时间与核心循环

新生涯读取设备当前年份，并固定从该年夏季窗口开始。球员开局年龄固定为13岁，不再要求玩家填写与这一规则冲突的出生年月。存档保存开始年份和窗口编号，现实年份变化不会改变已有生涯。

游戏每年只有两个阶段：

- 夏季窗口；
- 冬季窗口。

不区分中国、欧洲、南美等地区的特殊赛历。

每个窗口最多提供：

- 1个必选核心选择；
- 0至1个附加选择。

固定循环：

1. 进入窗口；
2. 处理上一阶段结算；
3. 更新状态、伤病、关系、合同和队内地位；
4. 检查强制恢复或生涯安全事件；
5. 生成核心选择；
6. 必要时生成一个附加选择；
7. 应用即时和阶段性后果；
8. 汇总模拟俱乐部及国家队比赛；
9. 结算成长、数据、赛事、荣誉和知名度；
10. 生成半年报告并自动保存。

完整生涯约54个半年窗口，目标单局时长60至90分钟。

## 3. 位置

可选位置：

- ST
- LW、RW
- CAM
- LM、RM
- CM
- CDM
- LB、RB
- CB

不提供进攻型、均衡型、防守型等二次类型。生涯事件可以改变训练分配，技术特点由长期能力变化自然形成。

主位置熟练度为100%。开局可以选择一个相邻副位置，熟练度92%，不占用职业生涯唯一一次学习新位置的机会。

职业生涯只允许选择一个新的学习位置。暂停后只能继续学习同一个位置，不能改学第二个位置。

位置熟练度：

| 类型 | 熟练度 |
|---|---:|
| 主位置 | 100% |
| 开局副位置 | 92% |
| 学习中 | 65%至89% |
| 学习完成 | 92% |
| 特殊情况下客串陌生位置 | 70% |

## 5. 隐藏潜力

每项长期能力都有独立隐藏潜力。先生成位置综合潜力目标，再按位置分配到四项潜力。

| 隐藏综合潜力 | 层级 | 概率 |
|---|---|---:|
| 65至68 | 普通职业球员 | 15% |
| 69至75 | 国内优秀球员 | 25% |
| 76至82 | 高水平留洋球员 | 30% |
| 83至88 | 世界级潜质 | 20% |
| 89至94 | 历史级潜质 | 10% |

因此：

- 60%的开局潜力达到76以上；
- 30%的开局潜力达到83以上。

四项潜力上限99、下限20。位置核心潜力至少比当前能力高15，重要能力至少高12，次要能力至少高8，极低权重能力至少高5。

## 6. 成长

单项成长：

> 年龄成长池 × 发展环境系数 × 训练份额 × 潜力差系数 × 固定种子随机系数

固定种子随机系数为0.9至1.1。

年龄成长池：

| 年龄 | 每半年成长池 |
|---|---:|
| 13至15 | 7.0 |
| 16至18 | 6.0 |
| 19至21 | 5.0 |
| 22至24 | 4.0 |
| 25至27 | 2.5 |
| 28至30 | 1.2 |
| 31至33 | 0.8 |
| 34岁以上 | 不再正常成长 |

潜力差系数：

| 潜力差 | 系数 |
|---|---:|
| 25以上 | 1.00 |
| 15至24.99 | 0.80 |
| 8至14.99 | 0.55 |
| 3至7.99 | 0.25 |
| 0.01至2.99 | 0.08 |
| 0 | 0 |

正常训练时，25%的成长池固定分配给玩家选择的重点能力，其余75%按位置权重分配。平衡训练不设置固定重点。

事件主要改变训练条件和份额。普通事件不直接给予巨大长期能力增长，稀有直接成长通常不超过0.5至1点。

发展指数：

> 训练质量40% + 出场锻炼25% + 队内关系10% + 身体状态15% + 心理状态10%

发展倍率：

| 发展指数 | 倍率 |
|---|---:|
| 0至29 | 0.55 |
| 30至44 | 0.75 |
| 45至59 | 0.90 |
| 60至74 | 1.00 |
| 75至89 | 1.12 |
| 90至100 | 1.20 |

31岁以后身体能力进入衰退。34岁以后进攻、防守和心理也可能缓慢下降。衰退受身体管理、伤病历史和状态影响，实际倍率为80%至150%。

## 7. 俱乐部训练质量

不单独设置教练水平对象。教练基础水平与俱乐部级别绑定，教练关系影响实际训练效果。

俱乐部保存：

- `clubTier`
- `facilityTier`
- `academyTier`

等级均为1最好、6最弱。

| 等级 | 设施分 | 青训分 | 教练基础分 |
|---|---:|---:|---:|
| 1 | 95 | 95 | 94 |
| 2 | 88 | 87 | 87 |
| 3 | 80 | 78 | 79 |
| 4 | 71 | 68 | 70 |
| 5 | 61 | 58 | 60 |
| 6 | 51 | 48 | 50 |

有效教练水平：

> 教练基础分 ×（0.85 + 教练关系 × 0.003），最高100

青年队训练质量：

> 设施35% + 青训环境45% + 有效教练20%

一线队训练质量：

> 设施45% + 青训环境10% + 有效教练45%

教练更换时只重置教练关系，教练基础水平仍由俱乐部级别决定。

## 8. 当前状态

三项状态均为0至100：

- 竞技状态；
- 身体状态；
- 心理状态。

13岁开局：

| 状态 | 初始值 |
|---|---:|
| 竞技 | 50 |
| 身体 | 90 |
| 心理 | 65 |

比赛状态修正：

> 1 +（竞技-50）×0.003 +（身体-50）×0.002 +（心理-50）×0.002

最终限制在0.75至1.25，只作为表现与事件概率修正，不直接乘到长期综合能力上。

状态安全规则：

| 状态值 | 处理 |
|---|---|
| 46以上 | 正常 |
| 36至45 | 警告，提高恢复事件概率 |
| 21至35 | 下一窗口强制P1恢复事件 |
| 0至20 | 立即触发P0恢复事件 |

以下情况也强制恢复：

- 两项以上状态低于46；
- 任一状态连续两个窗口低于46。

恢复事件必须有免费安全选项。连续两窗口低迷至少恢复15点或向45靠拢；连续三窗口至少恢复20点。多项低迷使用一次综合恢复事件。

## 9. 关系、知名度与归属感

五项关系均为0至100，开局为50：

- 教练；
- 队内；
- 经纪人；
- 球迷；
- 媒体。

另有：

- 知名度0至100；
- 当前俱乐部归属感0至100。

普通关系变化通常不超过15，重大冲突不超过25。

作用：

- 教练关系影响训练与选拔；
- 队内关系影响发展、心理和更衣室事件；
- 经纪人关系影响报价与谈判；
- 球迷关系属于当前俱乐部；
- 媒体关系描述舆论框架，不等同于知名度。

转会后：

- 媒体关系按`旧值×0.8 + 50×0.2`回归；
- 高知名度使新队内关系更容易融入；
- 离队只保存俱乐部ID、离队时队内关系、球迷关系、归属感和离队类型。

新队内关系的知名度加成：

| 知名度 | 加成 |
|---|---:|
| 0至19 | 0 |
| 20至39 | +2 |
| 40至59 | +4 |
| 60至79 | +6 |
| 80至100 | +8 |

每次成年队转会触发一次入队事件。豪华聚餐、与队长教练沟通、参加球迷活动和低调加练分别服务不同关系目标，不存在统一最优选项。

## 10. 球队层级、角色与出场

球队层级只有：

- 青年队；
- 一线队。

青年队角色：

- 轮换；
- 主力；
- 核心。

一线队角色：

- 边缘；
- 替补；
- 轮换；
- 主力；
- 核心。

队长是独立布尔值，不属于角色等级。

一线队能力基准：

| 俱乐部级别 | 基准 |
|---|---:|
| 1 | 85 |
| 2 | 80 |
| 3 | 74 |
| 4 | 68 |
| 5 | 62 |
| 6 | 56 |

青年队基准分别为48、45、42、39、36、33。

统一选拔分：

> 位置综合能力 +（竞技-50）×0.06 +（教练关系-50）×0.04 +（心理-50）×0.02

位置竞争修正：

- 严重缺人：-4；
- 较弱：-2；
- 正常：0；
- 较强：+3；
- 明星占据：+6。

正常情况下角色每半年最多变化一级。转会、晋升、新教练、长期伤病、伤愈、降级和位置转换可以立即重评。

一线队出场比例：

| 角色 | 比例 |
|---|---:|
| 边缘 | 5%至20% |
| 替补 | 20%至40% |
| 轮换 | 40%至65% |
| 主力 | 65%至90% |
| 核心 | 80%至95% |

青年队轮换、主力、核心分别为35%至55%、65%至85%、80%至95%。

青年队晋升候选条件：

- 年龄至少16岁；
- 青年队主力或核心；
- 竞技状态至少50；
- 没有中度以上伤病；
- 一线队选拔分距离基准不超过8。

## 11. 比赛数据

普通比赛按半年汇总，不逐场模拟。每半年最多0至2场关键比赛单独处理，并从汇总比赛数中扣除。

各位置每90分钟基础进球/助攻：

| 位置 | 进球 | 助攻 |
|---|---:|---:|
| ST | 0.32 | 0.10 |
| LW、RW | 0.20 | 0.17 |
| CAM | 0.14 | 0.22 |
| LM、RM | 0.10 | 0.18 |
| CM | 0.08 | 0.16 |
| CDM | 0.04 | 0.09 |
| LB、RB | 0.03 | 0.12 |
| CB | 0.04 | 0.03 |

进球能力系数：

> 0.45 + 进攻×0.006 + 身体×0.0025 + 心理×0.002

助攻能力系数：

> 0.50 + 进攻×0.0065 + 身体×0.001 + 心理×0.0025

期望数据：

> 分钟/90 × 位置基础率 × 能力系数 × 球队进攻系数 × 状态系数

最终由固定种子泊松分布生成。通常限制在期望值的40%至180%，期望值低于1时不设置最低结果。

评分由位置综合能力适配、状态、球队结果、数据波动和小幅随机组成，范围5.5至8.5。后卫主要通过位置综合能力、稳定性和球队防守表现获得公平评分。

青年队数据与职业成年队总数据分开。

## 12. 俱乐部与联赛世界

中国俱乐部全部虚构，但可参考现实中超和中甲俱乐部进行改写。

海外俱乐部使用真实名称，范围包括：

- 欧洲五大联赛顶级和次级俱乐部；
- 比利时、荷兰、葡萄牙顶级联赛；
- 日本、韩国顶级联赛；
- 巴西、阿根廷顶级联赛。

真实俱乐部名称必须位于可替换静态数据层，不使用队徽、球衣、赞助商、真实球员和真实教练。

完整世界约350家俱乐部，但不保存阵容和逐场结果。每家俱乐部每赛季只生成一个赛季分数。

联赛质量范围：

| 联赛类型 | 质量 |
|---|---:|
| 五大联赛顶级 | 75至82 |
| 荷兰、葡萄牙 | 69至74 |
| 五大联赛次级 | 63至70 |
| 比利时、巴西、阿根廷 | 66至72 |
| 日本、韩国 | 59至66 |
| 中国顶级 | 56至62 |
| 中国次级 | 50至56 |
| 抽象低级别 | 44至52 |

每国只模拟一个国内杯赛；洲际赛事只保留一级和二级两档；不模拟超级杯和完整杯赛对阵树。

## 13. 合同与转会

转会类型：

- 永久转会；
- 纯租借；
- 自由转会；
- 续约；
- 国内青训转会。

不提供租借加买断。

年龄限制：

- 16岁以前只允许国内流动；
- 16至17岁可以获得海外关注和未来意向，但不正式完成国际转会；
- 18岁以后开放完整国际转会。

合同字段：

- 类型；
- 俱乐部ID；
- 剩余半年数；
- 税前年薪；
- 承诺角色；
- 解约金；
- 俱乐部选项年数；
- 租借时的母队ID。

不包含签字费、出场奖金、表现奖金和降级减薪。

每个窗口最多出现3份正式报价，加上留队选项。谈判只允许一次反报价，方向为更高工资、更高角色或更低解约金。

首份职业合同属于职业阶段入口：已正式晋升的球员获得一线队角色承诺，尚未晋升的球员获得青年队职业合同。为避免当前阶段被单次随机结果卡死，首份合同反报价失败时保留原报价；后续普通转会仍按70%保留、30%撤回处理。

租借只允许半年或一年，到期回归母队；不模拟租借费、工资分摊和买断。

## 14. 知名度与市场价值

知名度开局5至10，随出场、联赛曝光、表现和里程碑增长。知名度越高，增长越慢。

市场价值为派生值，不写入存档。

基础能力锚点：

| OVR | 基础价值 |
|---|---:|
| 34 | €10,000 |
| 40 | €30,000 |
| 49 | €100,000 |
| 59 | €500,000 |
| 69 | €3,000,000 |
| 76 | €12,000,000 |
| 84 | €60,000,000 |
| 89 | €120,000,000 |
| 94 | €200,000,000 |

锚点之间线性插值，再乘年龄、公开潜力估计、知名度、联赛、近期表现和健康系数，最终限制在€5,000至€250,000,000。

市场价值不包含合同影响，转会费再乘合同剩余时间、角色和买方因素。

## 15. 工资与职业可支配现金

合同展示税前年薪。系统统一从工资中扣除税费、经纪人佣金、住房、日常生活、保险、医疗和长期资产配置，不单独模拟这些项目。

进入游戏现金的累进比例：

| 税前年薪分段 | 比例 |
|---|---:|
| 前€50,000 | 30% |
| €50,001至€150,000 | 25% |
| €150,001至€500,000 | 20% |
| €500,001至€2,000,000 | 12% |
| €2,000,001至€5,000,000 | 8% |
| €5,000,000以上 | 5% |

每半年加入当年可支配收入的一半。

## 16. 国家队

只模拟中国成年国家队，不模拟国青、国奥和奥运会。

世界杯周期为2026加4的倍数，亚洲杯周期为2027加4的倍数。

各国家队基础实力来自版本化的FIFA世界排名快照，不在运行时联网。中国队获得+5游戏性加成，该加成影响比赛和赛事结果，不改变球员入选门槛。

普通征召自动处理，只有带伤参赛、俱乐部冲突、重大赛事和退出国家队等情况要求玩家选择。

30岁以后可以主动退出国家队，决定不可逆。

## 17. 伤病

每半年最多记录一次会造成缺阵的伤病。基础风险8%，再由负荷、身体状态、身体能力、年龄、伤病史、训练和国家队负荷修正，最终限制在3%至40%。

严重程度在下调后的比例：

| 等级 | 比例 |
|---|---:|
| 轻微 | 57% |
| 中度 | 30% |
| 重大 | 12% |
| 职业威胁 | 1% |

轻微伤病自动采用标准治疗。中度以上提供标准康复、充分康复、冒险复出和专家治疗等选项。安全标准方案免费。

长期能力或潜力损失只在伤愈时应用。重大伤病后下一个半年不会出现职业威胁级伤病，并在两个窗口内降低再次重大受伤概率。

伤病永远不会自动强制提前退役。

## 21. 半年事件系统

事件优先级：

| 级别 | 类型 |
|---|---|
| P0 | 生涯安全：极低状态、重大伤病、合同到期无队、40岁退役 |
| P1 | 重大职业决定：转会、续约、租借、晋升、国家队退役 |
| P2 | 发展和地位：训练、新位置、首发、教练要求 |
| P3 | 人际和舆论：队友、经纪人、球迷、媒体 |
| P4 | 日常职业事件 |

没有特殊事件时，核心选择固定为半年发展计划。

完整版目标约84个参数化事件模板。事件保存ID、选择ID和必要结果摘要，不保存正文。

当前测试版先实现12个模板，覆盖教练要求、位置职责、队友竞争、更衣室冲突、媒体关注、网络批评、球迷活动、疲劳预警、带伤比赛、合同角色和转会传闻。每个窗口最多出现一个，使用生涯种子确定性抽取，并支持一次跨窗口后果；后续扩充内容时沿用同一事件定义和存档结构，不增加运行时世界记忆。

重复控制只读取：

- 最近6个事件ID；
- 事件组冷却；
- 少量选择计数；
- 最多5条有效长期承诺。

如果同一窗口出现三个以上必须处理的问题，只保留最重要的两个，其他问题采用安全方案自动处理并写入报告。

## 22. 开局与首个半年

开局顺序：

1. 输入姓名、偏好球衣号码和惯用脚；
2. 选择主位置和相邻副位置；
3. 排列出场、竞技、工资、稳定四项追求；
4. 选择留洋倾向和最多三个偏好联赛；
5. 生成球员并锁定随机种子；
6. 从豪门、中型和小型三种取舍明显的青训邀请中选择；
7. 完成一次入队事件；
8. 选择第一个半年发展计划；
9. 模拟青年队半年；
10. 查看报告并自动保存。

首半年保护：

- 不出现中度以上伤病；
- 不被青训营解约；
- 不触发强制退役或长期无球可踢；
- 单项关系不会因一次事件跌破35；
- 仍允许合理的低迷、角色和状态变化；
- 保护仅持续第一个半年。
