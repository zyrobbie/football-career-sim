# 俱乐部完整参数表 V1 审核说明

## 阶段结论

已根据《俱乐部与联赛数据库 V1 审核稿》生成 366 家俱乐部的完整参数审核表，覆盖 19 个联赛，包含唯一 `club_id`、六档平台、六项差异化参数、训练质量派生值、特征标签和名单来源。

工作簿已转换为 366 条只读 TypeScript 数据；生成器和 `generate:clubs:check` 已建立，40 个旧运行时 ID 具有兼容映射。数据已接入运行时目录、训练质量和转会报价，并已有完整公开 gameStore 工作流回归与 36 局固定种子压力测试。队徽资产层已独立接入：四家中国虚构俱乐部使用原创 SVG，其他俱乐部继续使用文字短标或等待授权审核的资产。

## 生成原则

- 六档平台只决定数值区间，不直接决定最终值。
- 最终值由平台基准、联赛环境修正、稳定的俱乐部级微调和人工特征修正共同构成。
- 每家俱乐部包含：设施、青训、工资、曝光、一线队门槛、年轻球员倾向。
- 青年队与一线队训练质量由公式派生，不再另外手填两组重复数据。
- 12 家已确认样板采用人工锁定，不受批量规则波动影响。
