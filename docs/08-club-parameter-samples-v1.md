> 状态：366 家静态参数已全部生成并可查询；40 家旧运行时 ID 保持兼容。参数已参与训练质量和一线队分钟成长，366 家目录已进入转会市场；存档结构与 `SAVE_VERSION` 未因参数接入改变。
> 对象：12家典型俱乐部
> 目的：先验证六项参数与成长结果，再批量扩展至366家俱乐部。

## 1. 六项参数

六项参数全部使用0至100的连续指数。六档平台只给出初始区间，不直接决定最终数值。

| 参数 | 含义 | 主要影响 |
|---|---|---|
| 训练设施 | 场地、设备、医疗和一线队日常训练条件 | 青年队及一线队训练质量 |
| 青训质量 | 青训体系、梯队培养和青年教练资源 | 青年队训练质量 |
| 工资水平 | 俱乐部支付能力，不是具体欧元工资 | 合同年薪区间及转会吸引力 |
| 曝光度 | 联赛、欧战、媒体和俱乐部关注度 | 知名度、国家队与后续市场 |
| 一线队门槛 | 成为一线队稳定成员的能力基准 | 实际角色、出场和合同承诺 |
| 年轻球员倾向 | 俱乐部给年轻球员机会的意愿 | 晋升速度、青年合同和角色容忍度 |

“年轻球员倾向高”不等于“训练质量高”。广西联城可能愿意早用新人，但培养资源仍明显弱于Ajax。

## 3. 样板之间的职业选择

### 国际米兰与Ajax

- 国际米兰的工资、曝光、一线队训练和竞争门槛更高；
- Ajax青训更强，年轻球员倾向显著更高；
- 相同能力的年轻球员在Ajax更容易获得一线队轮换，而在国际米兰更可能留在青年队或成为一线队边缘；
- 因而Ajax不是“全面弱化版国际米兰”，而是另一条更适合兑现潜力的路径。

### Ajax与Brighton

- 两队平台接近；
- Ajax青训和年轻球员倾向更高；
- Brighton工资与媒体曝光更高，五大联赛正式出场的经验价值也更高；
- 玩家需要在培养确定性与英超平台收益之间取舍。

### Como、Bologna与Venezia

- Como按已经确认的T2处理，资金、设施与曝光明显高于普通意甲中游；
- Bologna竞技平台略低，但青训与年轻球员通道更加均衡；
- Venezia资源较弱，一线队门槛更低，适合优先争取出场时间。

### 中国三级样板

- 上海东港提供国内最高工资、曝光和训练条件，但一线队竞争更强；
- 武汉江城各项资源下降，但更愿意稳定培养年轻球员；
- 广西联城资源最弱，却最愿意提前给新人一线队机会；
- “留在国内豪门青年队”和“去次级球队踢一线队”因此会产生实际差异。

## 5. 关键成长场景验算

以下场景统一采用教练关系 50、身体状态 70、心理状态 70、均衡训练且无事件加成；结果包含角色修正与一线队正式比赛经验。最终值仍受1.55上限约束。

| 场景 | 假定半年分钟 | 综合发展倍率 | 结论 |
|---|---:|---:|---|
| 国际米兰青年队核心 | 0 | 1.540 | 顶级纯培养环境 |
| Ajax一线队轮换 | 700 | 1.541 | 高于国际米兰青年队核心，规则成立 |

| Brighton一线队主力 | 1000 | 1.508 | 正式英超比赛弥补纯训练差距 |
| 上海东港青年队核心 | 0 | 0.987 | 国内顶级培养基准 |
| 广西联城青年队核心 | 0 | 0.739 | 明显弱于国内豪门，需依靠一线队出场补偿 |

### 验收结果

- 国际米兰青年环境至上海东港青年环境的倍率差为0.553；
- 上海东港至广西联城的倍率差为0.249；
- 世界级环境与中国豪门之间的差距，大于中国豪门与中国次级队之间的差距；
- Ajax一线队轮换高于国际米兰青年队核心；
- 国际米兰一线队零出场边缘低于本队青年队主力；
- 同一俱乐部的一线队稳定出场仍会高于青年队同级角色。

## 6. 批量扩展规则

审核通过后，366家俱乐部不逐家凭感觉手填，而使用“联赛基准＋平台区间＋俱乐部特征”生成初稿：

1. 联赛决定工资、曝光和比赛经验的大范围；
2. 六档决定综合平台与一线队门槛区间；
3. 俱乐部特征调整设施、青训和年轻球员倾向；
4. 所有值限制在相邻档合理重叠区间，允许同档差异；
5. 对豪门、著名青训队、升降级队和中国虚构队进行人工复核；
6. 用固定的跨队对照场景跑自动断言，防止后续调参破坏已确认关系。

俱乐部参数通过运行时俱乐部 ID 查询，已参与训练质量与一线队正式比赛经验成长；366 家目录也已参与合同和转会候选流程。此次接入不迁移存档结构，不改变既有公式或本节已经确认的样板数值。
