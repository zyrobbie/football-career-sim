# 金球奖实际可达性审计

产品已采用方案 B。本次只修改金球荣誉加成规则、回归测试和本文档；未改成长、比赛、转会、合同、国家队、存档或 UI。

## 最终生产公式

硬资格保持不变：俱乐部 `tier <= 2`、赛季至少 24 场、真实 OVR 至少 84。竞争线仍通过既有固定随机流抽取 `114–124`。

`金球分 = 平均评分 × 10 + (进球 + 助攻) × 0.35 + OVR × 0.25 + 荣誉贡献`

荣誉贡献只读取本赛季已结算的荣誉：

| 本赛季团队荣誉 | 贡献 |
|---|---:|
| 无联赛冠军、无洲际顶级俱乐部赛事冠军 | 0 |
| 仅联赛冠军 | +6 |
| 仅洲际冠军 | +12 |
| 洲际冠军＋联赛冠军 | +14 |

| 本赛季个人荣誉 | 额外贡献 |
|---|---:|
| 金靴 | +4 |
| 联赛最佳球员 | +5 |
| 赛季最佳阵容 | +0 |

因此洲际冠军＋联赛冠军＋金靴＋联赛最佳的总荣誉贡献为 23；洲际冠军与联赛冠军不会被重复计算成 18。最佳阵容不额外加分，避免与评分信号重复。

在欧洲对应欧冠，在南美对应解放者杯；奖励依据 `CareerHonorType.CONTINENTAL_TITLE`。亚洲俱乐部当前因平台档位无法通过金球 `tier <= 2` 的硬资格。

## 修正后的真实模拟口径

每组运行 200 个固定 seed：OVR 82/84/88/90/92，分别在 T1（国际米兰）和 T2（亚特兰大）。审计从 27 岁夏季 `windowIndex=28` 到冬季 `29`，四项 `potentials` 等于四项 `attributes`。每个样本均用 `calculateOverall()` 验证开始、夏季结算、冬季荣誉结算 OVR 全部等于标称值，并重放生产 `personal-honors` 随机线，逐样本验证审计镜像与实际 `BALLON_DOR` 一致。

## 未采用对照：方案 A

方案 A 保留旧荣誉计算（洲际顶级俱乐部赛事冠军 +8，否则联赛冠军 +4，且无个人奖加分），仅把竞争线降为 108–118。对应比率为：84/T2 0.5%、88/T2 2%、90/T1 1%、90/T2 4%、92/T1 5%、92/T2 9%，其余本批为 0%。方案 A 未被采用。

每赛季概率不等于完整生涯至少一次金球的概率；连续多个巅峰赛季和真实玩家策略分布仍需独立的全生涯审计。当前未验证国家队大赛应否影响金球权重。
