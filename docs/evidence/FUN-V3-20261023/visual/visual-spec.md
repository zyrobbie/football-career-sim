**2．个人安排采用一处展开区，依次完成类型、档位与确认。**

推荐嵌入半年计划的既有可选设置区域附近，避开策略与训练选项之间，保持原有训练比较的连续性。

```text
个人安排   本年可购买／本年已使用   [展开]
现金 €…    心理剩余1期 · 安顿剩余2期

展开后：
[身体] [心理] [安顿]                         [收起]

○ 档位名称                         €…
  每期收益与持续期／一次性收益
○ 档位名称                         €…
  每期收益与持续期／一次性收益
○ 档位名称                         €…
  每期收益与持续期／一次性收益

已选方案、付款前后余额、每期／期数／理论总量
当前限制、封顶提示、起效时间
[确认支付 €…]   [本次不安排，继续]
```

- 默认是一条横向入口，普通情况目标高 44–64px。窄屏或两个服务并行时，摘要可以自然增加一行；入口和展开按钮仍属于同一紧凑区域。
- **年度购买额度、现金余额、服务剩余期数是三个不同字段**，不用含混的“剩余次数”代替。
- 类型选择为等宽三列，点击区域至少 44px 高。中文类型名可换行，不缩字号。
- 只展示当前类型的三档。三档在手机、桌面均采用纵向紧凑条目，便于比较名称、费用和效果；不平铺九张卡。
- 档位条目以整行为选择目标，普通文案参考高 56–76px；长文自然增高，不裁剪关键内容来满足高度。
- 三档逐项显示价格及主要收益／代价。不能让用户点选后才发现费用或限制。
- 每次仅保留一个共用详情与确认区。切换类型或档位后，摘要、费用和提示同步更新。
- 展开区顶部有明确“收起”；关闭、返回、取消与购买成功分别呈现，避免把退出选择表现为已经购买。
- 免费继续路径持续可见。按钮表达“本次不安排”，年度额度是否变化严格按已确认规则回显，不由视觉层推断。

服务正式名称、九档价格及效果由父端已确认的规则提供；这里不重新确定数值。

**3．付款确认必须把花费和分期效果讲清楚。**

采用内联确认区，避免在窄屏中再套一层复杂弹窗。选中档位之后，支付之前至少显示：

| 信息 | 展示要求 |
|---|---|
| 购买对象 | 类型、档位全称 |
| 本次费用 | 完整货币金额，不用 `10k` 代替确认金额 |
| 现金变化 | `当前现金 €… → 支付后 €…` |
| 效果时间 | 一次性或每期；起效窗口按实际规则标明 |
| 持续效果 | 每期收益、总期数、理论总量同时出现，字号同级 |
| 当前限制 | 封顶、恢复优先、购买资格或余额不足，确认前直接可见 |
| 最终动作 | `确认支付 €…`，金额与上方一致；取消有明确出口 |

例如规划中的“心理每期 +2 × 2期”，确认区应同时写明“每期 +2、持续 2期、理论合计 +4”，并说明实际收益受状态上限影响。不能只突出“+4”。

对身体状态、心理状态和对应长期能力使用完整、准确名称，避免“身体 +2”被理解成永久能力增长。

余额不足、年度额度已使用、安顿条件不满足等情况，显示具体原因。当前状态饱和与未来服务可能收益分开解释；是否允许购买按规则处理，UI 不自行制定禁购条件，也不承诺未来一定获得理论总量。

**4．逐期显示现金与服务进度，报告呈现实际结算。**

计划入口保留当前现金、本年购买状态及有效服务摘要。两个服务同时有效时，各占一条紧凑说明，不合并成一个“剩余 3期”。

| 场景 | 必须能直接看懂的信息 |
|---|---|
| 服务进行中 | 服务／档位、本期是第几期、当前剩余期数 |
| 本期已执行 | `心理支持：本期实际 +2，执行后剩余 1期` |
| 封顶或部分生效 | `计划 +2，实际 +1（状态上限），剩余 1期` |
| 实际收益为零 | 显示 `实际 +0` 和原因；期数变化按真实执行结果显示 |
| 年度额度刷新、旧服务仍在 | `本年可购买` 与 `旧服务剩余 1期` 同时显示 |
| 两种服务重叠 | 分别列出本期实际收益及剩余期数 |
| 服务完成或终止 | 明确完成／终止及原因；有退款时显示实际退款金额 |
| 本期现金 | 当前余额；付款、退款作为明确项目与既有现金记录衔接 |

“剩余期数”必须有时间口径：计划页为当前尚未执行的期数，报告为本期结算后的剩余期数。不能在同一状态下出现互相矛盾的两个数字。

报告中区分：

- 服务的名义收益；
- 服务实际贡献；
- 包含其他事件和消耗的半年净变化。

现金同理，不能把全期余额变化全部归因于个人安排。展示读取结算结果，不在界面上另算一套收益或退款。

**结算后不出现“领取”按钮。** 成功提示可以强调已经生效或已安排，但不增加一个需要再次领取的步骤。
