- Current impression disclosure text uses the existing compact detail pattern; no new score/milestone wall. The long synthetic evidence can be fully reached above bottom navigation.
- Production src ownership stayed with developer; this role wrote only QA scripts, fixtures and reports. Deployment/Pages publication is parent-owned and untested here.
