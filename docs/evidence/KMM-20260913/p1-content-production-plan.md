## 创作与验收约束

1. 五组各至少四类判断；审查传球、射门、抢点、持球支点、节奏、转换、防守补位、出球等实际差别。跨位置可共享一种球场局面，组内不能只换标题和名词。
2. PASS的正面结果必须实际写出队友破门并对应助攻；SHOT写出自己的进球；只控球/防守的结果不得虚构进球或助攻。黄牌只能在有相应代价的结果中出现，并在选择前可知。
3. 不写固定领先、落后、补时绝杀、德比、特定对手或已夺冠，当前随机分钟/比分没有提供这些保证。不额外添加资格系统来迁就文案。
4. 注意时序：球已踢出就不能重新选择传中线路；已完成的配合可作为背景，但当前动作与三个结局必须能衔接。禁止让“先回做”无缘由变成自己射门，或“自己带球”直接记为一次助攻。
5. 数值由执行者在已批准规则范围内确定；每个动作有适配画像，所有120动作/360结果最终实际审阅。新目录扩充不修改旧Pending/Result/报告快照，已有12模板数值尽量保持。
6. 文字短、风险直观，说明合并展开；13/12/11px和44px以上触区基线不变。不能用更大的字、更长的卡片包装新内容。
