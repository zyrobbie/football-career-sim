# S4 统筹执行口径（准备，待S3放行）

## 输入与运行数

使用 inputs-handoff.md 的100份冻结开局raw，核对SHA并直接加载。完整输入偏好范围如实保留，不改年龄、能力或潜力来改善结果。

同一100种子执行：100次OFF、100次ON属性适配、100次ON稳定轮换，共300次完整生涯。两组ON使用相同的OFF对照；OFF复用不再计100次独立运行。所有非Moment决策政策相同，先锁定并存文档后运行。

OFF通过测试环境的功能模拟或已提供的纯OFF入口实现，不增加面向用户的开关，不把ON也绕过。若OFF借助新Pending中的未结算基础输入回到SIMULATION_READY再调用纯OFF入口，必须明确说明此测试接缝，并与S0原算法等价证据衔接。ON使用真实Store公开选择/完成动作。

## 固定决策及不变量

- 属性适配按S0已定顺序：成功率高者优先，然后预期黄牌低者，再按A/B/C固定顺序；轮换按已发生Moment序号A/B/C。
- 训练沿用合法分龄选项和恢复规则；先声明具体政策。事件只选当前可用选项，分支建立和最终选择均按稳定ID顺序；市场用合法报价的固定排序，不能用随机列表顺序或事后挑选较好结果。
- 每条运行有有限动作上限（建议1000），无合法后继或存储错误时保留最小反例，不强改状态继续冒充成功。完整生涯到原规则合法退休，不提前主动退休来缩短样本。
- 每次正式报告只新增一条history且旧前缀不变；无重复窗口；数值有限、合同/球队身份一致；Moment选择及结果不提前消费后果或现金。
- Pending/Result/READY和最终状态的保存恢复均需可核验；同一raw重复执行选定代表样本，检查确定性。不把重复执行计成新种子。

## 比较与触发观察

按全体、位置和选择政策报告进球、助攻、评分、荣誉、出场、职业长度、Moment次数；保留每条生涯的完整最终数据与精简逐窗轨迹。

区分Moment直接贡献和通过原角色/出场/市场路径产生的总差。8%进球、10%助攻是观察线，超出时解释分母、位置及绝对变化并交统筹判断，不为过线结果擅自调原算法。不要把评分规则增量当最终显示差。

从实际ON运行记录至少1000个合资格普通窗口。首秀、青年/零出场单列；普通窗口按上一窗有/无Moment分桶，报告实际计数和比例，与45%/75%设计比较。确定性样本上的观察不能冒称精确概率证明。若不够1000，明确缺口，按事先有界方案补样，不无界搜索。
