# 绿茵生涯 V1.0.0 正式版发布审计

审计日期：2026-08-22
发布分支：`main`
发布标签：`v1.0.0`

## 已完成功能

- 建档、固定种子球员生成、青训邀请、入队、青年队成长与一线队晋升。
- 职业合同、续约、合同到期市场、自由转会，以及国内、海外和豪门受阻三类报价路径。
- 半年训练、比赛分钟、能力成长、报告、特殊事件（含多阶段交互）、国家队与大赛、俱乐部和个人荣誉。
- 40岁强制退休及合同到期的最后一年退休规则；退役档案由现有履历汇总生成。
- 退役档案可生成带固定网址二维码的 PNG 生涯记录；二维码独立校验不重写源 SVG。
- 本地自动存档、继续生涯与删除生涯；四项只读导航为生涯、球员、履历、设置。
- 366家运行时俱乐部、19个联赛，且40家旧运行时 ID 继续兼容。

## 本地公开浏览器验收

验收使用独立来源 `http://localhost:4174/` 创建的一次性生涯“RC验收球员”，未接触线上存档或其他本地来源。此前“新建生涯”自动化超时已确认是已有存档时出现原生 `window.confirm`、自动化未并行处理确认框所致，不是页面或新建生涯逻辑故障。

- 首页经覆盖确认后完成五步建档、球员揭晓与青训邀请；接受河南中原邀请后，完成入队选择、半年训练与半年报告。
- 流程推进到真实特殊事件“**一段比赛集锦让你受到额外关注**”。事件未处理时，依次切换球员、履历、设置并返回生涯；原事件及其三项选择均保留，流程状态未丢失。
- 四项导航均可点击，当前项的 active 样式与 `aria-current` 正确。
- 在 `390×844` 视口，生涯、球员、履历、设置四页的 `document.scrollWidth` 均为 `390`；固定底部导航不遮挡主要内容，未出现横向溢出。
- 在 `1280×720` 视口，桌面侧栏与履历表格正常，页面 `scrollWidth` 为 `1280`，未出现横向溢出。
- 设置页第一次删除操作取消后，生涯与导航仍存在；在明确授权后再次确认删除，页面回到首页，“继续生涯”与“删除本地生涯”均消失，仅保留“新建生涯”。
- 全程浏览器控制台无新增 error 或 warn；临时验收服务与标签页已关闭。

这是一轮本地桌面浏览器验收，不等同于真实 iPhone Safari 或 Android Chrome 验收。

## 当前边界

- 不模拟真实完整阵容、教练名单、真实赛程或动态升降级。
- 仅四家中国虚构俱乐部使用原创 SVG 队徽；真实俱乐部资产仍待授权审核，其他俱乐部使用文字短标。
- 无云同步、账号系统、多存档槽或存档导入导出。
- 不宣称已完成真实移动设备、真实阵容、真实赛程、动态升降级或全部真实队徽。

## 结论

自动化、数据一致性、类型、构建、二维码、生产依赖安全及公开浏览器流程均已通过；产品方已完成多轮手机端实际游玩与问题回归，确认将当前版本发布为 **V1.0.0 正式版**。

正式版仍遵守上述产品边界。现有手机测试以 iPhone 浏览器为主，Android Chrome 仍属于发布后的兼容性观察项；这不影响 V1.0.0 的既定玩法闭环，但不得据此宣称已覆盖所有移动设备。
